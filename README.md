# وصّل | لوحة متابعة طلبات التوصيل

أنشأت هذه الصفحة لمساعدة موظفي شركة وصّل على متابعة طلبات الزبائن بدلًا من البحث عنها يدويًا، بحيث يقدر الموظف يشوف تفاصيل كل طلب وحالته بسهولة.

استخدمت HTML وCSS وBootstrap لتصميم الصفحة وترتيب العناصر، واستخدمت JavaScript لإضافة البحث والترتيب والتعامل مع بيانات الطلبات.

وضعت بيانات الطلبات في ملف JSON، وقسمت ملفات المشروع إلى مجلدات حتى يكون الكود مرتبًا وأسهل في التعديل والصيانة.
